# User Guide - Enterprise Knowledge Synthesis Platform

Welcome to the Multi-Modal Enterprise Knowledge Synthesis Platform! This guide will help you get started with using the chat interface to interact with AI and manage your documents.

## Getting Started

### 1. Creating an Account

1. Visit the platform homepage
2. Click "Sign Up" if you don't have an account
3. Fill in your details:
   - Full Name
   - Email address
   - Password (minimum 6 characters)
4. Click "Sign Up" to create your account
5. You'll be automatically logged in after successful registration

### 2. Logging In

1. Enter your email and password on the login page
2. Click "Sign In"
3. You'll be redirected to the main chat interface

## Main Interface Overview

The platform consists of three main areas:

### Top Navigation Bar
- **User Info**: Displays your name and avatar
- **Logout Button**: Click to sign out of your account

### Left Sidebar
- **New Chat Button**: Creates a new conversation thread
- **Thread History**: Lists all your previous conversations
- **Thread Indicators**: 
  - 💬 Chat icon for text-only conversations
  - 📄 Document icon for conversations with uploaded files

### Main Chat Area
- **Welcome Screen**: Shown when no thread is selected
- **Message History**: Displays conversation messages
- **Input Area**: Where you type messages and upload files

## Core Features

### 1. Starting a New Conversation

**Option A: Text-Only Chat**
1. Click the "New Chat" button in the sidebar
2. Start typing your message in the input field
3. Press Enter or click the send button

**Option B: Document-Based Chat**
1. Click the file upload button (📎) in the chat input
2. Select files from your computer, or drag and drop files
3. Wait for the upload to complete
4. A new thread will be created automatically
5. Ask questions about your uploaded documents

### 2. Uploading Documents

**Supported Methods:**
- **Click to Browse**: Click the file upload button and select files
- **Drag and Drop**: Drag files directly onto the chat input area

**Supported File Types:**
- PDF documents
- Text files
- Word documents
- Images (JPG, PNG, etc.)
- And more...

**Upload Process:**
1. Select or drag your files
2. See upload progress indicator
3. Wait for "Upload complete" message
4. Start asking questions about your documents

### 3. Chatting with AI

**Sending Messages:**
- Type your message in the input field
- Press Enter to send (Shift+Enter for new line)
- Or click the send button

**Message Features:**
- **Copy Messages**: Click the copy button on any message
- **Professional Format**: Clean, rectangular message bubbles
- **User Avatars**: "U" for your messages, "AI" for assistant responses
- **Typing Indicator**: Shows when AI is generating a response

### 4. Managing Conversations

**Thread Navigation:**
- Click any thread in the sidebar to switch conversations
- Thread names are automatically generated based on content
- Recent threads appear at the top

**Thread Types:**
- **Regular Chats**: General conversations with the AI
- **Document Threads**: Conversations about uploaded files

**New Features:**
- **Editable Thread Names**: Click on any thread name to edit it
- **Instant Message Display**: Your messages appear immediately when sent
- **In-Chat Upload Progress**: See upload progress within the conversation

## Tips for Best Results

### Document Upload Tips
1. **File Organization**: Upload related documents together for better context
2. **File Quality**: Ensure documents are readable and not corrupted
3. **File Size**: Larger files may take longer to process
4. **Multiple Files**: You can upload multiple files at once

### Chat Tips
1. **Be Specific**: Ask clear, specific questions for better responses
2. **Context Matters**: Reference your uploaded documents explicitly
3. **Follow-up Questions**: Build on previous responses for deeper insights
4. **Professional Tone**: The interface is designed for business use

### Navigation Tips
1. **Thread History**: Use the sidebar to quickly switch between conversations
2. **Document Indicators**: Look for file icons to identify document-based threads
3. **Search Conversations**: Scroll through message history to find previous discussions

## Troubleshooting

### Common Issues

**Login Problems:**
- Check your email and password are correct
- Ensure you have a stable internet connection
- Try refreshing the page

**File Upload Issues:**
- Check file format is supported
- Ensure file isn't corrupted
- Try uploading one file at a time
- Check your internet connection

**Message Not Sending:**
- Verify you're logged in (check top navigation)
- Ensure message isn't empty
- Check internet connection
- Try refreshing the page

**Thread Not Loading:**
- Refresh the page
- Try selecting a different thread first
- Check your internet connection

### Getting Help

If you encounter issues not covered in this guide:

1. **Check Browser Console**: Open developer tools to see any error messages
2. **Try Different Browser**: Test with Chrome, Firefox, or Safari
3. **Clear Cache**: Clear your browser cache and cookies
4. **Contact Support**: Reach out to your system administrator

## Privacy and Security

### Data Security
- All communications are encrypted
- Your documents are processed securely
- Login sessions use secure JWT tokens

### Data Privacy
- Your conversations are private to your account
- Uploaded documents are associated only with your user account
- Messages are not shared with other users

### Best Practices
- Log out when using shared computers
- Don't share your login credentials
- Use strong passwords
- Be mindful of sensitive information in uploads

## Keyboard Shortcuts

- **Enter**: Send message
- **Shift + Enter**: New line in message
- **Ctrl/Cmd + V**: Paste (including files)
